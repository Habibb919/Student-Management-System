Student Management System

A simple Python project for managing student records and grades.

Features

* Add students
* View all students
* Calculate average grade
* Find the highest grade
* Input validation
* Interactive menu

Concepts Used

* Python Functions
* Lists and Dictionaries
* Loops
* Conditional Statements
* Exception Handling

How to Run

Run the following command:python main.py
